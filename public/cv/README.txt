Downloadable CV
===============

File: meryne-ndjeyi-cv.pdf  (linked from the hero "Download CV" button
and the "CV" line in the Contact section, via personal.cvUrl in
src/data/content.ts)

To update it:
1. Export the new CV as PDF, ideally under 2 MB (in Canva: "PDF Standard",
   not "PDF Print"; compress photos if needed).
2. Name it exactly meryne-ndjeyi-cv.pdf and overwrite this file.
3. Commit and push: Vercel redeploys and serves the new version at once.

Visitors download it as "Meryne-Ndjeyi-CV.pdf" (personal.cvDownloadName).

Check before replacing: status "six-month internship from January 2027",
same English wording as the site if you want the two to match.
